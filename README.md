# College AI Assistant

An AI chatbot that answers student questions about the college,
built with Python, Streamlit and the Google Gemini API.

## Features
- Answers questions using college information from a text file
- Remembers the conversation
- Web chat interface built with Streamlit

## Setup
1. Clone the repository
2. Create and activate a virtual environment
3. Install dependencies: `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and add your Gemini API key
5. Run: `streamlit run app.py`

## Tech Stack
Python, Streamlit, Google Gemini API
